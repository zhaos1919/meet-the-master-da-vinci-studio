# 遇见画家｜达芬奇的虚拟画室

基于 Three.js 的可漫游 3D 画室演示，包含白天、黄昏、夜晚三组实时光照。

## 本地运行

```bash
npm install
npm run dev
```

打开 `http://localhost:3000/`。

## 操作

- 鼠标左键拖动：环视
- 滚轮：前后移动
- 双击《蒙娜丽莎》：靠近画作并打开细读面板
- 底部按钮：切换光照、自动漫游、重置视角和导出固定机位截图
